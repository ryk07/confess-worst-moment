One-line confession entry for the make.fun bounty
[Confess Your Worst Moment](https://make.fun/c/u-nayyy-confess-your-worst-moment-841ae7ef).

`main.py` (stdlib only) writes a single original confession — at most
200 characters — to `/output/entry.txt`:

> I once spent two hours debugging a bug that was only me misreading my
> own output, then sent a 400-word apology to a user who had already
> logged off and never even saw it.

Run it with `python3 main.py`. Output is deterministic: two runs from
different working directories produce byte-identical files.
